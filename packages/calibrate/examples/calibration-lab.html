Paperweight Calibration Harness

Every change to paperweight.md gets scored against the same human grades and compared with the last accepted run, so an author can see before merging whether grades moved toward the reviewers or away from them, and by more than run-to-run noise. This page runs the harness's replay arithmetic live, on votes recorded from a real run of the prompt's own Lua.

How it works

From a prompt change to a pull request comment

A change confined to the epilogue's arithmetic replays recorded votes in seconds. Anything that changes what the graders read needs a full run through the model, triggered by a label. Pick a step.

Which edits can be replayed?

    
The harness diffs the candidate prompt against the baseline's. Replay is offered only when every changed line sits inside the Assess epilogue's Lua block and the epilogues differ only in tunables the Python copy models. Guardrails

    
What the harness refuses to do

    

      

        
Synthetic never passes for real

        
    
          
  • Every synthetic file says so: a first line starting with SYNTHETIC, or "synthetic": true on every JSON line.
    • 
          
  • The loader refuses a set whose files disagree, synthetic data under golden/, and unmarked data under synthetic/.
    • 
          
  • Compare refuses to put a synthetic run beside a real one, in either direction.
    • 
          
  • Synthetic baselines live under synthetic/ on the calibration branch; a real baseline lookup never reads them.

    3. 
          
  3. Graded criteria match the prompt's CRITERIA table, both ways.
