How paperweight gets checked

Paperweight is an AI reviewer that reads a WG21 paper and scores how well it argues that its idea belongs in the C++ standard. The calibration harness is a safety net around it: whenever someone changes paperweight's rules, it shows whether the AI's scores moved closer to trusted human reviewers or further away.

    Where it stands today

    The whole loop is built and runs on every pull request. The real test papers and human grades haven't arrived yet, so for now it runs on practice data: real WG21 papers, pretend reviewer grades, and a stand-in for the AI.

    SYNTHETIC

    Every result made from practice data carries that stamp, so it can never be mistaken for a real finding about paperweight.

    What it guarantees

    • Rule changes get checked against the same papers every time.
    • Small math tweaks are checked for free, in seconds.
    • It tells real improvement apart from normal wobble.
    • Practice results and real results never mix.
